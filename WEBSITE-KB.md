## 2. Hosting, DNS, domain, and the deploy path

- **Host:** cPanel/Apache, public A record `167.235.93.90`.
- **DNS:** Cloudflare nameservers. **Mail:** Microsoft 365 (MX). **Registrar:**
  OnlineNIC. (These are all public via DNS/WHOIS.)
- **Deploy path — the mechanism:** push to GitHub → in cPanel, Git Version
  Control → **Update from Remote** → **Deploy HEAD Commit**. Deploys happen
  **only on that manual click**; pushing to GitHub never auto-deploys.

  change, a one-time hard refresh clears any year-cached copy from before this

## 3. Takwa Website Editor (Duaa's tool)

- **Path:** `~/obsidian/George/Takwa/start.py`. Python `ThreadingHTTPServer`,
  `PORT = 8099`, binds `127.0.0.1` (this computer only), password-gated (scrypt
  hash in `.takwa-tools-auth.json`, gitignored, per machine, unrecoverable if
  forgotten — delete the file to set a new one).
- **Start it:** desktop icon **"Takwa Website Editor"** (`~/Desktop`, runs
  `takwa-tools.sh`), or `takwa-tools.sh` (Linux) / `takwa-tools.bat` (Windows).
  URL: `http://localhost:8099`.
- **What it edits:**
  - `/_photo-index.html` — every image on the site (change / undo / remove / blank).
  - `/_text-index-ar.html` — every Arabic string next to its English original.
  - `/_add-product.html` — products: add / edit / delete, brand (Enna / Flavora
    Cafe), category, sizes, Arabic name/short/full.
  - `/_add-news.html` — news articles, Arabic.
  - `/_add-position.html` — open positions, Arabic (added Sep 2026).
- **Helper scripts:** `build_arabic.py` (generate every `-ar` page),
  `translations_ar.py` + `translations_ar_overrides.json` (Arabic table + the
  overrides the editor writes), `text_engine.py` (byte-exact HTML text edits),
  `rebuild-text-index.py`, `rebuild-sitemap.py`. `swap-photo.py` is **superseded**
  by the photo index. `_photo-backups/` holds pristine page copies and the data
  manifests (`_products.json`, `_news.json`, `_positions.json`).
- **How an edit reaches live:** the **Publish** button in the editor commits and
  pushes to GitHub (pulling/rebasing first if behind). Then **George deploys**
  from cPanel. Not direct — two locks (push, then deploy).

## 4. Duaa's workflow (one screen)
